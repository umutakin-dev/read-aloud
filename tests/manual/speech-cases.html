How to use: start Read Aloud on this page and listen. Under each case, the green line is what you should hear; a beige line means the text should be read exactly as written. Neither line is read aloud, and nor is this note.

Opened as a file, Chrome needs “Allow access to file URLs” on the extension. Or serve it: python3 -m http.server -d tests/manual 8000, then open localhost:8000/speech-cases.html.
