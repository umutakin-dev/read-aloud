# Make Read Aloud pleasant to use

**Type:** 👑 Epic
**Status:** 📋 Backlog
**Priority:** 🟡 MEDIUM
**Tracked In:** local
**Created:** 2026-08-03

## Description

What separates something that works from something people reach for.

The accessibility item (#000038) is not really polish and sits at the top for that reason: this is a reading tool, so being unusable without a mouse or a screen reader undercuts the point of it. Being able to click a paragraph and start there (#000039) is the single biggest interaction win available and is cheap, because the mapping from page text to chunks already exists.

The rest — progress and scrubbing (#000040), voice preview (#000041), server-side caching (#000042), other languages (#000043) — are ordinary product work, worth doing once the foundations under #000024 and #000028 are settled.

Note that #000042 assumes a server still exists; if #000025 moves synthesis into the browser, caching becomes a different problem (or none at all).


- #000038 ✨ Keyboard controls and screen reader support for the toolbar
- #000039 ✨ Click a paragraph to start reading from there
- #000040 ✨ Show progress through the document and allow scrubbing
- #000041 ✨ Preview a voice before choosing it
- #000042 🔧 Cache synthesized audio so a re-read is instant
- #000043 ✨ Support languages other than American English
