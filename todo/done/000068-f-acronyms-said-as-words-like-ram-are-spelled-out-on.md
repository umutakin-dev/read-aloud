# Acronyms said as words, like RAM, are spelled out on the browser engine

**Type:** ✨ Feature
**Status:** ✅ Done
**Priority:** 🟡 MEDIUM
**Tracked In:** local
**Created:** 2026-11-26 09:38 UTC

## Description

On the browser engine, "16 gigabytes of RAM" is heard as "R-A-M". espeak-ng spells a short all-caps word in lowercase text unless it knows it (NASA, JPEG); the server's misaki has a dictionary and says "ram".

Fix: take the all-caps words misaki's dictionary says exactly like their lowercase form, keep those whose espeak reading changes when lowercased, and send them lowercase. The list is generated by a script and committed; a lowercase word is the same length, so highlighting is untouched.
